# HARU PICK — 브랜드 랜딩 페이지 (GitHub Pages)

리빙·주방 물건을 조용한 에디토리얼 톤으로 소개하는 **HARU PICK** 반응형 원페이지입니다.

- 라이브: https://qntmdgus64-cloud.github.io/moodstore/
- 구성: `index.html` (단일 파일, CSS·JS 인라인) + `assets/` (이미지 13개, 약 1.3MB)
- 라인업 (2026-11-17 교체): 힘멜 법랑사각 14/16cm 39,900 · 담음공방 온감 14P 33,900 · 모인샵 도자기 화병 뷰티 55,900 · 힘멜 에센스 커트러리 4P 16,900 · 힘멜 하우스 커트러리 4P 17,900 · 바디솔라 BM-5001 98,000 · 프리폼 차렵이불 42,600
- 섹션: 에디터스 픽 · 스토리 · 신상품 · 컬렉션 · 저널 · 룩북
- 상호작용
  - 상품 카드 → 상품 상세 오버레이(가격·구성·관리·매장 위치 이동)
  - 컬렉션 패널 → 컬렉션별 물건 목록 오버레이, 항목에서 상품 상세로 연결
  - 저널 카드 → 서론·본문·맺음말이 있는 에디토리얼 읽기 오버레이, 글 끝 '소개된 상품 보기'로 상품 연결, '저널 전체 보기'는 아카이브
  - 룩북 6컷 → 고화질 라이트박스(캡션·좌우 이동·관련 상품 링크)
  - 모든 오버레이는 ESC·배경 클릭·브라우저 뒤로가기로 닫힘
- 반응형 브레이크포인트: 기본(모바일) / 760px(태블릿) / 1040px(데스크톱)
- 폰트: Google Fonts — Noto Serif KR(제목) + Noto Sans KR(본문), 미로드 시 시스템 폰트로 대체
- 갱신 방법: `index.html` 또는 `assets/` 교체 후 `main`에 커밋·푸시 → 1분 내 자동 배포
