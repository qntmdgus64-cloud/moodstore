# HARU PICK — 브랜드 랜딩 페이지 (GitHub Pages)

모던한 주방 도기·식기·화병을 조용한 에디토리얼 톤으로 소개하는 **HARU PICK** 반응형 원페이지입니다.

- 라이브: https://qntmdgus64-cloud.github.io/moodstore/
- 구성: `index.html` (단일 파일, CSS·JS 인라인) + `assets/` (이미지 18개, 약 1.6MB)
- 라인업 (2026-11-17 개편 · 8종, 모두 판매 중인 상품의 실제 사진)
  - 담음공방 온감 직사각 그라탕기 17,900 · 온감 핸디보울 3색 세트 40,900 · 온감 홈세트 14P 33,900
  - 포슬 타원접시 2P 세트 33,900
  - 힘멜 법랑사각 냄비 14/16cm 39,900 · 에센스 커트러리 4P 16,900 · 하우스 커트러리 4P 17,900
  - 모인샵 도자기 화병 뷰티 55,900
  - 제외: 바디솔라 맥반석 찜질기, 차렵이불, 폴라니에 악센트볼(무드 불일치)
- 섹션: 에디터스 픽(4) · 스토리(포슬) · 상품 전체(8) · 컬렉션(법랑의 색 / 온감의 그릇) · 저널(3) · 룩북(6컷, 인스타그램 @harupick.official 연결)
- 이미지 원칙: **사진 속 물건은 모두 실제 판매 상품**입니다. 컬렉션 배너·룩북도 실물 컷만 사용하며, AI 연출컷·판매하지 않는 상품 사진은 쓰지 않습니다. `assets/col_enamel.jpg`는 힘멜 3종 실물 컷을 크림 바탕에 배치한 카탈로그 플레이트입니다.
- 상호작용
  - 상품 카드 → 상품 상세 오버레이(가격·구성·스펙·매장 위치 이동)
  - 컬렉션 타일 → 컬렉션별 물건 목록 오버레이, 항목에서 상품 상세로 연결
  - 저널 카드 → 본문 오버레이, 글 끝 '소개된 상품 보기'로 연결, '저널 전체 보기'는 아카이브
  - 룩북 6컷 → 라이트박스(캡션·좌우 이동·관련 상품 링크)
  - 모든 오버레이는 ESC·배경 클릭·브라우저 뒤로가기로 닫힘
- 반응형 브레이크포인트: 기본(모바일) / 760px(태블릿) / 1040px(데스크톱)
- 폰트: Google Fonts — Noto Serif KR(제목) + Noto Sans KR(본문), 미로드 시 시스템 폰트로 대체
- 이미지 재생성: `scratch/build_moodstore_assets.py` (원본 `tmp/29cm_candidates`, `tmp/modern_tableware` → `assets/`)
- 갱신 방법: `index.html` 또는 `assets/` 교체 후 `main`에 커밋·푸시 → 1분 내 자동 배포
